## 🎉 新功能

### Frame 尺寸縮放

V2P v1.1.0 新增了強大的 Frame 尺寸縮放功能，讓您可以在影格擷取時自由調整影片尺寸。

#### 核心特性

✨ **自由尺寸調整**
- 支援 1-8192 像素的自由調整
- 長寬比鎖定功能，調整一個值自動計算另一個
- 即時預覽原始尺寸與縮放後尺寸對比

🎯 **四種縮放模式**
1. **拉伸變形** - 直接填滿目標尺寸
2. **裁切中心** - 保持比例，裁切超出部分
3. **填充黑邊** - 保持比例，填充黑色背景
4. **填充透明邊** - 保持比例，填充透明背景（PNG 專用）

⚡ **快速比例選擇**
- 一鍵選擇常用比例：1:1、16:9、9:16、4:3
- 「原始」按鈕自動讀取並設定影片原始比例
- 自訂比例輸入（1-999）

#### 使用場景

| 場景 | 建議設定 | 效果 |
|------|---------|------|
| 遊戲角色動畫 | 拉伸變形 + 原始比例 | 保持品質，減少檔案 |
| UI 圖標 | 填充透明邊 + 1:1 | 正方形，透明背景 |
| 移動端優化 | 裁切中心 + 512x288 | 快速處理，節省空間 |
| 背景動畫 | 填充黑邊 + 16:9 | 完整畫面，統一尺寸 |

#### 範例操作

**將 1080p 影片縮小到 512x288**:
```
1. 上傳影片 → 顯示「ⓘ 原始尺寸：1920x1080」
2. 勾選「啟用 Frame 尺寸縮放」
3. 點擊「16:9」→ 自動設定比例
4. 拖動寬度 Slider 到 512 → 高度自動變為 288
5. 選擇「拉伸變形」
6. 開始轉換
```

**橫向轉正方形（保持畫面完整）**:
```
1. 上傳 1920x1080 影片
2. 啟用縮放 → 點擊「1:1」
3. 寬度設為 1080 → 高度自動 1080
4. 選擇「填充黑邊」或「填充透明邊」
5. 轉換 → 上下添加邊框
```

## 🔧 改進項目

### 偏好設定增強
- 自動儲存縮放相關參數（啟用狀態、比例、尺寸、模式）
- 下次開啟時自動載入上次使用的縮放設定

### Metadata 完整記錄
新增縮放資訊記錄：
```json
{
  "original_size": "1920x1080",
  "frame_resize_enabled": true,
  "frame_size": "512x288",
  "resize_mode": "stretch"
}
```

### 日誌系統增強
- 記錄完整的 FFmpeg 縮放命令
- 記錄原始影片尺寸
- 縮放參數驗證日誌
- JPG 格式降級警告

### 新增工具函數
- `get_video_dimensions()` - 獲取影片原始尺寸
  - 優先使用 ffprobe
  - 回退到 ffmpeg -i 解析
  - 支援多種尺寸格式

## 📊 性能優化

### 處理速度提升
縮小尺寸可顯著減少處理時間：

| 縮放比例 | 相對處理時間 |
|---------|-------------|
| 100% (1920x1080 → 1920x1080) | 1.0x |
| 67% (1920x1080 → 1280x720) | 0.8x |
| 27% (1920x1080 → 512x288) | **0.4x** ⚡ |

### 檔案大小優化
縮小尺寸可大幅減少最終材質大小：

| 尺寸 | 100 幀材質大小 (PNG) |
|------|---------------------|
| 1920x1080 | ~15MB |
| 1280x720 | ~9MB |
| 512x288 | **~2.5MB** 💾 |

## 🛠️ 技術細節

### FFmpeg 濾鏡實現

**拉伸變形**:
```bash
-vf "fps=24,scale=512:288"
```

**裁切中心**:
```bash
-vf "fps=24,scale=512:512:force_original_aspect_ratio=increase,crop=512:512"
```

**填充黑邊**:
```bash
-vf "fps=24,scale=512:288:force_original_aspect_ratio=decrease,pad=512:512:(ow-iw)/2:(oh-ih)/2:black"
```

**填充透明邊**:
```bash
-vf "fps=24,scale=512:288:force_original_aspect_ratio=decrease,pad=512:512:(ow-iw)/2:(oh-ih)/2:color=black@0"
```

### UI 事件處理
- 長寬比聯動計算（基於 GCD 演算法）
- 即時提示資訊更新
- 自動啟用/停用子元件
- 快速比例按鈕一鍵設定

## ⚠️ 注意事項

### 限制與建議

1. **透明邊模式**
   - ⚠️ 僅支援 PNG 格式
   - JPG 會自動降級為黑邊模式並記錄警告

2. **超大尺寸**
   - 尺寸 > 4096 會增加處理時間
   - 系統會發出警告提示

3. **格式選擇**
   - 需要透明：PNG + 填充透明邊
   - 檔案優先：JPG + 適當品質
   - 品質優先：PNG + 低品質值（1-5）
