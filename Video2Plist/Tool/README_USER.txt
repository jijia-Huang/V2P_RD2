📝 簡介
────────────────────────────────────────────────────────────

V2P 工具可以將 MP4 影片轉換為 Cocos2d-x 遊戲引擎使用的 plist 格式
動畫序列，支援影格縮放、去背處理、材質打包等功能。

🚀 快速開始
────────────────────────────────────────────────────────────

1. 雙擊 v2p.exe 啟動程式
2. 等待命令提示字元視窗顯示啟動訊息
3. 瀏覽器會自動開啟 (http://127.0.0.1:7860)
4. 如果沒有自動開啟，請手動在瀏覽器輸入上述網址

💻 系統需求
────────────────────────────────────────────────────────────

- 作業系統：Windows 10 或更高版本
- 記憶體：建議 8GB 以上
- 磁碟空間：至少 500MB 可用空間
- 網路：不需要（本機運行）

📖 使用步驟
────────────────────────────────────────────────────────────

【基本轉換】

1. 點擊「轉換」頁籤
2. 上傳 MP4 檔案
3. 設定 FPS（影格率）
4. 輸入輸出名稱（例如：walk_animation）
5. 點擊「開始轉換」
6. 等待處理完成

【進階功能】

📐 Frame 尺寸縮放：
- 拉伸變形：直接縮放到目標尺寸
- 裁切中心：保持比例，裁切超出部分
- 填充黑邊：保持比例，空白處填充黑色
- 填充透明邊：保持比例，空白處透明（PNG）

🎨 去背處理：
- 僅支援 PNG 格式
- 可在「去背預覽」頁面調整容差值
- 自動檢測影格四個角落的背景色
- ⚠️ 注意：與「填充模式」搭配使用可能效果不佳

📁 輸出位置
────────────────────────────────────────────────────────────

轉換後的檔案會儲存在：

v2p.exe 所在目錄 / videos / v2p_動畫名稱/

包含：
- *.plist - 動畫描述檔
- *.png / *.jpg - 材質圖片
- *_metadata.json - 動畫資訊

🎮 Lua 整合
────────────────────────────────────────────────────────────

如果您使用 Cocos2d-x Lua：
1. 將 Lua/AnimationLoader.lua 複製到專案中
2. 參考 Lua/AnimationLoader_使用指南.md

⚙️ 設定說明
────────────────────────────────────────────────────────────

【設定頁面】

FFmpeg 路徑：
- 工具內建 FFmpeg，通常不需要設定
- 如需使用自訂版本，請在此設定路徑

TexturePacker 路徑（可選）：
- 若安裝了 TexturePacker，可設定路徑使用
- 未設定時會使用內建的 Python 打包器

TinyPNG API 金鑰（可選）：
- 用於進階圖片壓縮
- 需到 https://tinypng.com/developers 申請

🔧 常見問題
────────────────────────────────────────────────────────────

Q1: 程式無法啟動？
A: 檢查防毒軟體是否阻擋 v2p.exe，或嘗試以系統管理員身分執行

Q2: 轉換失敗？
A: 查看 log 資料夾中的日誌檔案（v2p_YYYYMMDD.log）

Q3: 無法上傳檔案？
A: 確保檔案格式為 MP4，且檔案大小不要太大（建議 < 500MB）

Q4: 去背效果不理想？
A: 
   - 到「去背預覽」頁面調整容差值
   - 如果使用了「填充模式」縮放，改用「拉伸」或「裁切」模式
   - 確保影片背景是純色

Q5: 處理速度很慢？
A: 
   - 降低 FPS
   - 減小材質尺寸限制
   - 縮小 Frame 尺寸
   - 不要同時處理多個影片

Q6: 輸出檔案很大？
A:
   - 使用 JPG 格式（檔案較小，但不支援透明）
   - 啟用 TinyPNG 壓縮
   - 降低輸出品質值

📊 效能建議
────────────────────────────────────────────────────────────

一般影片：
- FPS: 12-24
- 材質大小: 2048x2048
- 輸出品質: 5

高畫質需求：
- FPS: 24-30
- 材質大小: 4096x4096
- 輸出品質: 1-3

省空間需求：
- FPS: 8-12
- 材質大小: 1024x1024
- 輸出品質: 10-15
- 格式: JPG

📂 目錄結構
────────────────────────────────────────────────────────────

v2p.exe          # 主程式
config.yaml      # 工具設定（自動生成）
preferences.json # 使用者偏好（自動生成）
log/             # 日誌檔案
videos/          # 輸出目錄
temp/            # 臨時檔案（可定期清理）
preview/         # 預覽檔案（可定期清理）

🛡️ 安全性說明
────────────────────────────────────────────────────────────

- 本工具完全在本機運行，不會上傳任何資料
- 不需要網路連線（除非使用 TinyPNG 壓縮）
- 所有檔案處理都在本機進行

⚠️ 注意事項
────────────────────────────────────────────────────────────

1. 關閉程式時，請關閉命令提示字元視窗或按 Ctrl+C
2. 處理過程中請勿關閉視窗
3. 定期清理 temp 和 preview 資料夾以節省空間
4. 建議定期備份 videos 資料夾中的重要輸出
5. 首次使用建議先用小檔案測試
